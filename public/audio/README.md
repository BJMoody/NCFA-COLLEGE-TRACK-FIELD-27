# NCFA College Track & Field 27 audio assets

The browser game looks for voice and stadium audio under `./public/audio/`.

Use **MP3** for voices and long ambience. Use **WAV** for starter gun, recall gun and bell transients.

Missing files are allowed: the game will continue and procedural crowd / gun fallbacks can still play.

## Voice direction

PA announcer: clear stadium voice, measured cadence, slight public-address projection, neutral American accent, never overexcited.

Broadcast commentators: natural live-sports delivery, reacting rather than reading, varied pacing, occasional short pauses. Do not sound like a hype trailer.

Officials: concise, authoritative, calm, no broadcast personality. Starter commands should be clean and isolated so timing can be randomized by the game.

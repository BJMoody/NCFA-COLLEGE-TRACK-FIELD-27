# Controls

## Current 800m prototype

| Input | Action |
| --- | --- |
| W / Up Arrow | Increase effort |
| S / Down Arrow | Reduce effort |
| A | Move outward after the break |
| D | Move toward the rail after the break |
| Space | Trigger a short surge |

## Planned controller mapping

| Controller | Action |
| --- | --- |
| Right Trigger | Increase effort |
| Left Trigger | Relax / control effort |
| Left Stick | Position on track |
| A / Cross | Surge / event action |
| Right Stick | Optional camera look |

Controller support is planned but is not wired into the current vertical slice yet.

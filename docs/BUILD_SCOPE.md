# Current Build Scope

This branch is the first playable browser foundation for NCFA College Track & Field 27.

Included:
- Browser boot and menus
- Career archetype selection
- Career hub
- 3D stadium and track
- Playable 800m race
- AI opponents
- Effort, stamina, drafting, positioning, surge and results
- GitHub Pages deployment workflow

Future systems remain tracked in the roadmap and game-design documentation.

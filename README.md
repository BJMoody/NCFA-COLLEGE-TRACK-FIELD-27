# NCFA College Track & Field 27

A high-fidelity collegiate track & field career and program-management game built in Unreal Engine 5.8.

## Vision

NCFA College Track & Field 27 is an original college-sports universe centered on track & field. The game combines athlete career progression, team dynasty management, academics, training, recovery, recruiting, indoor/outdoor seasons, cross country, championship qualification, broadcast presentation, and event-specific competition systems.

## Core modes

- **Career** — Create an athlete, get recruited, attend classes, train, compete, transfer, chase records, and build a four-year legacy.
- **Dynasty** — Run a collegiate program, recruit athletes, allocate scholarships, manage event groups and staff, develop athletes, and chase team championships.
- **Quick Meet** — Jump directly into an event or full meet.
- **Championship** — Play through conference and national championship structures.
- **Online** — Planned competitive multiplayer and meet experiences.

## Career archetypes

- Sprint
- Distance
- Jumps
- Throws
- Combined Events

## Technology

- Unreal Engine 5.8
- C++ gameplay foundation with Blueprint-facing systems
- Enhanced Input
- Gameplay Tags
- Data-driven athlete/event definitions

## Current milestone

The first vertical slice targets a complete track race loop with athlete attributes, race phases, fatigue, drafting, pacing, AI strategy, timing, placing, and results. Career, season, recruiting, academic, recovery, and meet systems are scaffolded alongside it so the project can expand without rewriting the foundation.

> NCFA is a fictional governing body created for this game. The project is not affiliated with the NCAA, EA Sports, or any real collegiate athletic association.
